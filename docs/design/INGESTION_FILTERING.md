# 邮件接入与过滤设计

邮件账号分别维护 IMAP UID 游标、租约和同步任务。首次连接只记录当前基线；历史导入由单独的预览和批次管理，不推进实时游标。收取、索引和 Agent 分析使用独立持久任务。

过滤规则按账号保存。白名单优先，随后执行黑名单、主题/正文关键词与分类规则。证据不足或字段解析失败的邮件进入待复核。过滤、归档、放行均只修改本地数据库，不会更改远端邮箱。

测试入口为 `tests/test_filtering.py`、`tests/test_mail.py` 和 `tests/test_mail_extended.py`。完整验证命令及运行归档见 `docs/MAIL_TESTING.md`。
