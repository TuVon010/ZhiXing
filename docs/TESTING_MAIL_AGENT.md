## 证据怎么查

`manifest.json` 查看命令和退出码；`backend-junit.xml` 查看用例；`backend.log` 查看失败堆栈；`evaluation` 查看逐例规则输入输出；`browser/results` 查看截图、录像、Trace；`pytest-data` 和 `browser/database` 保存隔离测试数据库。

本轮没有进行真实邮箱登录/投递、主模型质量测试、本地检索消融或大规模压力测试。这些不能由模拟通过替代。研究方法见 [工作台指南](WORKSPACE_GUIDE.md) 和 [测试留档说明](MAIL_TESTING.md)。
