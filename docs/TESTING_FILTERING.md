# 邮件过滤测试记录

过滤只改变知行本地的邮件状态，不会删除或移动邮箱服务器上的邮件。规则按邮箱账号隔离并带版本；白名单优先，黑名单和关键词随后执行，分类置信度不足时进入待复核。

## 可复现范围

运行 `pytest tests/test_filtering.py tests/test_mail.py -q`。覆盖规则校验、账号隔离、重复处理、广告分类、白名单覆盖、过滤箱恢复、索引排除及收取任务失败恢复。输出记录放在 `artifacts/test-runs/`，失败轮次也保留。

## 人工检查

1. 为两个测试邮箱分别配置互不相同的规则，确认规则和版本不会串号。
2. 将一封合成广告邮件放入过滤箱，检查过滤原因和命中规则。
3. 将发件人加入白名单后重新处理，确认邮件可恢复进入本地收件箱和索引。
4. 检查过滤状态不会发出远端删除、归档或移动命令。

测试默认使用合成邮件。模拟通过不代表真实邮箱服务商的收取权限已验证。
